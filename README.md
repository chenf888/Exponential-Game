# 指数增长 (Exponential)

> 纯粹的指数增长 · 见证数字的力量

一个基于 **ExpantaNum.js** 数值引擎的中文增量/放置游戏，支持天文级数字运算、离线进度、多线程模拟、多种计数法、双语界面。

---

## 📖 项目简介

《指数增长》是一款纯前端增量游戏。核心玩法极其简单：**每过一秒，点数翻 ×1.05 倍**。攒够点数后购买升级，进一步提升增长倍率，最终达到 `2^1024` 触发 **大坍缩**，进入无限升级树。

游戏使用 `ExpantaNum.js` 作为数值引擎，能表示到 `{10, 9e15, 1, 2}` 级别的超级天文数字，天然支持 `ee5`、`E42#8`、`10^^n` 等超越科学计数法的表示。

---

## 🎮 玩法说明

### 核心循环

| 概念 | 说明 |
|------|------|
| **点数 (Points)** | 游戏的主货币，随每秒增长不断累积 |
| **倍率** | 每秒点数乘上的系数。新档基础为 ×1.05，每次升级叠加 |
| **增长率** | 实际每秒增长百分比，由基础倍率 + 自我增强共同决定 |
| **大坍缩** | 点数达到 2^1024 触发，重置进度，获得 Infinity Point |

### 升级树

| 编号 | 名称 | 效果 | 价格 |
|------|------|------|------|
| **U1** | 指数增强 | ×1.05 → ×1.07/秒 | 1e10 |
| **U2** | 超指数增强 | ×1.07 → ×1.12/秒 | 1e15 |
| **U3** | 超级无敌指数增强 | ×1.12 → ×1.22/秒 | 1e25 |
| **U4** | 自我增强 | 额外 +X%/秒，X 随点数增长 | 1e60 |
| **U5** | 可持续发展 | 每次购买 +1%/秒，可无限购买 | 1e153（每次 ×1e33） |
| **U6** | 无聊到炸裂 | 基础倍率 ×1.22 → ×1.37/秒 | 1e130 |
| **U7** | 预留扩展 | 未来版本开放 | — |

> **自我增强公式**：`X = max(log₁₀(pts) / D − S, 0)`
> - 未购 IU2：`D=20, S=3`
> - 已购 IU2：`D=15, S=4`
> - 零点对齐于 U4 价格（1e60），购买瞬间 X 恰好为 0%

### 无限升级 (需完成大坍缩)

| 编号 | 名称 | 效果 | 价格 |
|------|------|------|------|
| **IU1** | 无限基础 | 基础倍率 ×1.05 → ×1.13/秒 | 1 IP |
| **IU2** | 无限加速 | 自我增强公式 ÷20−3 → ÷15−4 | 1 IP |
| **IU3** | 无限折扣 | 所有升级价格 ÷ max(log₂₅(pts), 1) | 1 IP |

## ✨ 特色功能

### 🔢 九种计数法

在【设置】页可自由切换：

| 计数法 | 示例 | 说明 |
|--------|------|------|
| 混合 | `1.23M` → `1.23e15` | K/M/B → 后缀 → 科学 |
| 英文单位 | `1.23Qa` → `1.23Ce` | 完整短尺度单位表 |
| 字母 | `A` → `Z` → `AA` → `BA` | 千进制、双射 26 进制无限进位 |
| 科学 | `1.23e456` | 标准科学计数法 |
| 对数 | `e1.23` | 显示 10 的指数 |
| 欧米茄 Ω | `β₆₉` → `ω^ω^ω₃₃₃` | 严格移植 cook1ee 官方实现 |
| 中文长 | `六千万亿` | 以「亿」为基准无限叠加 |
| 中文短 | `亿兆京垓秭穰沟涧…` | 古代单位序列 + 华严经延伸层 |
| 神秘 | `381后1个零` | 严格三位尾数 + 零的个数 |

### ⏳ 离线进度系统

- 关闭页面后自动模拟离线收益（上限 14 天）
- 支持 **Web Worker 多线程并行模拟**，跑满 CPU 核心
- 可配置线程数与 Tick 上限
- IndexedDB 兜底存档，意外退出不丢档
- **智能时间跳变检测**：页面被系统冻结/杀死后自动结算

### 🚀 时空跃迁

- 每次离线获得 **储存时间**（离线秒数 × 0.1）
- 离线收益的 **10%** 转化为 **时空碎片**
- 消耗储存时间发动「时间跳跃」，立即模拟对应时长
- 支持预设 1/10/60/600 秒与自定义秒数

### 💾 存档系统

- **自动存档**：每 10 秒一次
- **存档箱**：手动存档最多保留 100 份历史记录（默认关闭，可在设置开启）
- **导出/导入**：JSON → 两次 Base64 加密，可复制备份或分享
- **原子写入**：临时 key + 覆盖，防止半写损坏
- **旧存档迁移**：兼容 v1~v11 及 OmegaNum 格式

### 🎓 新手教程

- Undertale / Deltarune 风格对话框
- 角色「欧米伽」带你过一遍核心玩法
- 打字机逐字显示，点击/空格/回车推进
- 强制过一遍，看完写入存档；设置页可随时重看

### 🎵 借用作者力量

- 每次打开页面仅一次
- 60 秒内每秒增长率额外 +1%
- 播放作者主题曲（whyp.it 直链）

### ⚠️ 危险操作二次确认

清除存档、读档、导入存档、时空跃迁、借用作者力量等不可逆操作均会弹出确认框，防止误触。

### 🛡️ 全局错误监控

- NaN / Infinity 主动检测，发现数值污染立即暂停游戏并弹窗
- 异步 Promise 错误捕获
- ExpantaNum 库加载校验
- 错误计数显示（第 N 次错误）

## 🛠️ 技术栈

| 项目 | 说明 |
|------|------|
| **数值引擎** | [ExpantaNum.js](https://github.com/Naruyoko/ExpantaNum.js)（纯 JS，无依赖） |

## ⚠️ 注意事项

- 游戏数据保存在浏览器 `localStorage`，清除浏览器数据会丢失存档，**建议定期导出备份**。
- 离线进度依赖 `localStorage` 的时间戳，修改系统时间可能影响离线结算准确性。
- 多线程离线计算需要浏览器支持 Web Worker；不支持时自动降级为单线程。
- 借用的作者主题曲来自外部 API，首次加载可能需要网络请求。
- 游戏内包含开发者模式（三击标题输入密码），仅供作者调试使用，普通玩家无需关注。
